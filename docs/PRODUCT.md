# LinkResan product overview

LinkResan is a Persian-first SaaS platform for professional link creation, management, analytics and distribution.

This public document describes product capabilities only. It is not a copy of private Production implementation.

## Product promise

Help users create better link experiences: create links, control behavior, understand usage and connect links to digital workflows.

## Audiences

### Creators
- short links
- custom aliases
- password protection
- expiration and click limits
- Link-in-bio

### Teams
- analytics capabilities
- custom domains
- collaboration features
- campaign-oriented workflows

### Developers
- API keys
- webhooks
- public integration concepts
